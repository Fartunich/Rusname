# RusNamePlugin

Плагин для Purpur 1.21.1 (совместим с Paper), который:

- при первом входе на сервер требует у игрока ввести в чат **Имя и Фамилию на русском языке**;
- пока имя не введено, игрок не может двигаться, ломать/ставить блоки, взаимодействовать
  с миром или использовать другие команды;
- после ввода сохраняет имя в `plugins/RusNamePlugin/names.yml` (привязка к UUID игрока,
  сохраняется даже если игрок сменит ник в Minecraft);
- показывает "Имя Фамилия" вместо ника в **чате** и в **табе** (списке игроков, Tab);
- команда `/setname <Имя> <Фамилия>` позволяет сменить имя позже.

## Сборка локально

Нужен установленный Maven и JDK 21.

```bash
mvn clean package
```

Готовый файл появится в `target/rusname-plugin.jar`. Положите его в папку `plugins`
вашего сервера Purpur и перезапустите сервер.

## Сборка через GitHub Actions

В проекте уже настроены два workflow (`.github/workflows/`):

- **build.yml** — собирает jar при каждом push/PR в `main`/`master` (и вручную через
  вкладку Actions → Run workflow). Готовый файл появляется во вкладке **Actions** →
  выбранный запуск → раздел **Artifacts** → `rusname-plugin`.
- **release.yml** — при push тега вида `v1.0.0` собирает jar и автоматически создаёт
  **GitHub Release** с прикреплённым `rusname-plugin.jar`.

### Как запустить

1. Создайте репозиторий на GitHub и запушьте туда содержимое этой папки:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin <URL вашего репозитория>
   git push -u origin main
   ```
2. Откройте вкладку **Actions** в репозитории — сборка запустится автоматически,
   jar будет доступен в Artifacts.
3. Чтобы получить релиз с прикреплённым jar, создайте и запушьте тег:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   После этого во вкладке **Releases** появится готовый `rusname-plugin.jar`.

Никаких дополнительных секретов настраивать не нужно — оба workflow используют
встроенный `GITHUB_TOKEN`.

## Формат имени

Принимаются два слова, каждое начинается с заглавной русской буквы и состоит из русских
букв (допускается двойное имя через дефис, например `Анна-Мария Иванова`).
Неверный формат — игрок увидит сообщение об ошибке и должен ввести имя заново.

## Настройка

- Регулярное выражение для проверки имени находится в `NameListener.java` и
  `SetNameCommand.java` (константа `WORD_PATTERN`), можно ослабить/усилить требования.
- Список действий, блокируемых до ввода имени, находится в `NameListener.java`
  (обработчики `onMove`, `onInteract`, `onBlockBreak`, `onBlockPlace`, `onCommand`) —
  при необходимости добавьте другие события (например, `EntityDamageByEntityEvent`).
